# welcome-set-up

On a fresh `temper box --fake-backends`, as the walk `box` (`temper help box`) walks
it ("Trying the welcome with nothing real"): the box's printed sign-in
link opened, the welcome drawn, "Set up temper" pressed, then "Choose"
on "Forgejo on this machine".

- `01.html`: the welcome as it was when "Set up temper" was pressed. Its
  "Set up temper" leads to `02.html`.
- `02.html`: the Forge step's choices, as they were when "Choose" was
  pressed on "Forgejo on this machine". Its "Choose" leads to `03.html`.
- `03.html`: Forgejo on this machine's details, its first repository's
  fields as offered, as they were when the recording ended.
