# temper ctl model

Kind: reference

Models: read those your party may use.

## model list

```
model list [--project PROJECT]
  --project PROJECT: a project's name or number; optional. Only this project
Read the models your projects may use, by provider
Prints: `models:`, each project's providers and models with their windows, efforts and prices, then the accounts and `digest: models`
--json: the record models.
Key: none.
Its digest is the models' read, not the accounts'; to wait on the
accounts, use the digest account list prints.
```
